# Epoch — AI/ML Club Projects

This repository contains assignments, exercises, and mini-projects completed as part of the AI/ML club's Epoch sessions at IIT Hyderabad.

The work covers classical machine learning, unsupervised learning, recommender systems, and deep learning.

## Repository Contents

### Session 1 — Classical Machine Learning
- Decision Tree implemented from scratch
- K-Nearest Neighbors (KNN) classifier
- Logistic Regression

### Session 2 — Unsupervised Learning
- K-means clustering
- DBSCAN clustering

### Session 3 — Neural Networks and Recommendation Systems
- Computational graph task
- Neural recommender system, including an NCF-related notebook

### Session 4 — Deep Learning
- Multimodal emotion recognition using CNNs and RNNs

## Technologies

- Python
- Jupyter Notebook
- Machine learning and deep learning libraries

## Purpose

The repository documents my learning and practical work through Epoch's AI/ML sessions. It provides a collection of implementations and experiments across several machine learning topics.

*Note: The repository contains session assignments and learning exercises; the scope and implementation details vary across projects.*
